# 基础研究项目的写法

## 面上：把一个值得深入的问题讲透

可从前沿认识、现实矛盾或前期异常现象起笔。需求导向项目可以先交代场景，但应尽快落到可以研究的关系；自由探索不强加产业背景。

有用的推进方式是：已有方法取得的进展 → 在特定条件下仍存在的限制 → 该限制提示的未知关系 → 本项目可区分解释的研究抓手。按研究路线或竞争解释组织现状，不按作者逐篇排队。

P05物理页9–10把已有三维结构的进展收束到入射与耗散难以同时改善，再用前期样品暴露结构设计与稳定性的后续问题。可学习这种“已有进展—剩余矛盾—可研究切口”，不能把其声学结论搬到其他体系。

前期结果说明可进入问题，但保留尚待解决部分。P08页20、P13页22均同时写初步结果、限制和可复用方法。以“已有何种证据支持哪一步”为基础段的落点，避免把主要拟研究问题提前写成已经解决。

## 青年探索与博士后：聚焦且体现独立判断

本库没有足够直接样本，以下为待新增范本检验的适配建议：

- 从一个明确缺口或新假设展开，说明为何选择该切口，不将完整产业链或多材料体系都塞入项目。
- 前期基础少时，可据实说明可执行方法、相关证据和关键风险；不虚构大量样品、论文或团队条件。
- 研究内容数量由问题和周期决定。独立性从选题、方法选择和承担工作体现，不机械增加“本人独立”措辞。
- 青年人才项目若主要评估既有贡献，转到人才文体；不要只凭“青年”二字选这一模式。

## 重点与重大基础研究：把系统问题拆开，再说明如何合起来

先概括共性问题、现有认识在哪些环节断开，以及项目为何需要系统研究。展开子任务时说明它提供的变量、对象、模型或证据将被谁使用；有真正平行的任务就明确并行及汇合点。

P02页13–16把分散、构筑、转化、改性和力学组织为五项研究内容、三类科学问题。P18页17–18先用总体构架说明溶胶、射流、陶瓷化与力学应用的联系，再展开模块。这里应学的是整合方式，不是五项任务或某条固定工艺链。

内容与科学问题可以多对多：两个制备任务可共同服务一个形成机制问题；一个共用表征平台也可支撑不同问题。每个连接须有解释，不能为了“一一对应”拆碎科学问题。

大项目的力度来自统一概念、边界明确的子问题和综合验证，不来自“重大、颠覆、国际领先”。重大项目还应依据实际指南处理课题层级，不能仅凭重点范本外推。

## 联合基金与培育：写明资源为何必要

先确定它属于面上式聚焦研究还是重点式系统研究。P01页7、11从动态过程难以观测引出同步辐射能力，并把设施落实到具体观测任务。迁移时应写“需要辨析的过程—所需能力—取得的证据”，不能只写平台名称或夸大其不可替代性。

培育性表达突出假设的依据、初步可行性和后续验证，不降低科学问题质量，也不在证据有限时承诺普适规律。
