# 项目书迭代修订经验

本文件中的材料变量、三模块顺序与机制例子来自既往具体项目，仅用于相关场景。主文体先由 project-types.md 判定；工程技术关键、人才贡献与报告不能一律套科学问题提纯。

本文件用于用户已经提供初稿、连续提出局部异议或要求全篇联动时。目标是减少“语言更顺但科学主线被改坏”的修订失败。

## 1. 先识别修订模式

| 用户请求 | 允许动作 | 禁止动作 |
|---|---|---|
| 优化一句 | 调整该句语序、主谓和逻辑 | 重写整段、引入新结论 |
| 精简10% | 按指定总幅度删冗余并保留关键逻辑，不要求各段等比例 | 删除小标题、数字、对照和判据 |
| 只加引用 | 插入标号、重排文献表 | 润色正文、改年份或术语 |
| 按此逻辑优化 | 保留事实，重组因果顺序 | 擅自扩大材料或环境范围 |
| 完整版 | 汇总所有已确认修改并消除残留 | 回退到早期被否定版本 |

用户说“不对”“太空”“和前面没关联”时，先诊断是哪一层失配：标题、科学问题、研究变量、证据链、段末总结或章节边界。不要仅换同义词。

## 2. 防止章节同义反复

同一项目的各部分应回答不同问题：

- 研究内容：研究哪些对象、变量和关系；
- 科学问题：哪条未知因果关系阻碍理解；
- 研究目标：完成后获得何种可验收认识；
- 研究方案：如何设计对照并获得因果证据；
- 创新点：相对已有研究增加了什么新机制或新方法；
- 年度计划：按时间完成哪些工作与阶段产物。

若把“揭示A调控B的机制”原样复制到所有章节，即使措辞不同，仍属于重复。

## 3. 把空话替换为研究设计

在用户授权完善因果研究方案且有事实依据时，检查以下四个要素；局部润色不能擅自补实验设计，未知内容标为建议或缺口：

1. **对照变量**：构型熵、混合焓、局域配位、晶粒尺寸、节点颈径比等；
2. **控制变量**：平均离子半径、价态、晶体结构、初始晶粒或纤维直径等；
3. **观测量**：扩散系数、迁移活化能、相变分数、裂纹密度、强度保持率等；
4. **因果判据**：何种比较能够区分熵效应、焓效应、主元化学作用或节点效应。

不要把更多仪器名称当作“具体”。具体性来自变量与判断逻辑。

## 4. 科学问题提纯

基础研究中仅写“如何制备”“如何测试”或“如何优化”通常不够，还需说明科学未知。可用以下结构诊断，但不强制每个问题都有竞争机制：

`已知现象/矛盾 + 可能竞争机制 + 未知关系或边界 + 为什么现有认识无法解释`

例如，理论计算得到平衡条件下的固溶倾向，而实际陶瓷化存在组元释放与晶化不同步；真正的问题是相形成热力学与前驱体转化动力学如何耦合并使实际组织偏离平衡预测，而不是简单提出“构建配位体系”。

## 5. 主体系与验证体系

跨三个材料体系全面铺开容易造成变量不可控、样品量过大和方案空泛。需要辨析机制时：

1. 选择结构明确、前期基础充分的模型体系；
2. 构建低/中/高水平或近单变量对照；
3. 用其他体系验证规律边界，而非重复所有实验。

选择模型体系时写明为什么能保持平均离子半径、价态、结构或初始组织可比。

## 6. 段落衔接与总结

- “在此基础上”要求前一结果是后一任务的输入；平行的理论与实验层面用“从……两个层面”更准确。
- 研究总述的段末应总结本段两条机制线索的共同作用，不能突然提出一个与前文无关的新对照设计。
- 三项内容之间采用“形成 → 组织—性能关联 → 服役演化”的递进时，第三部分应研究第二部分强化组织在环境中的保持或退化，而非重新讨论一遍初始强化。

## 7. 全篇联动

每次实质修改后搜索以下残留：

- 删除的环境变量是否仍出现在目标、创新点、年度计划和预期成果；
- 小标题是否仍使用旧研究重心；
- 摘要中的“首先—其次—最后”是否与三项研究内容对应；
- 项目题目中的核心词是否在科学问题和研究方案中都有实质内容；
- 图题、研究内容和正文用词是否一致，如“界面”是否误代“节点组织”或“内部组织”。

## 8. 引用插入

- 先按论断切分，再为每个最小论断选1–2篇最直接文献；领域综述与具体实验结果分开支撑。
- 用户要求编号按顺序且不重复时，允许重排文献表，但正文内容保持锁定。
- 一句话需要多篇文献时，将引文放到对应分句后；不要在句末堆5–6篇。
- 如现有文献不能支撑论断，可补检索一篇，但必须说明新增来源并核验真实性。
