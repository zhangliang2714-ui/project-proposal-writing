# 语言、逻辑与段落风格

## 用语言完成论证动作

默认正式、准确、紧凑。句长随解释任务变化；一条明确判断可以短写，复杂关系必要时用复句。高信息密度不是名词多，而是读者能辨认谁在什么条件下影响什么，以及依据在哪里。

需要重组现状、增强段落推进或模仿全文论证时，再读 [narrative-moves.md](narrative-moves.md)：选定比较轴、前期发现的双重功能、总述/内容/方案的不同信息层次，以及贡献和合作的表达动作。不要把它们全部套进每一段。

项目类别先由project-types.md决定。下表是可选择的论证动作，不是每段必填槽位。

| 段落任务 | 合适的推进 | 常见失误 |
|---|---|---|
| 界定背景 | 场景/前沿事实 → 对研究对象提出的要求 | 政策、宏大意义占满开头 |
| 评价现状 | 归纳一种路线的有效性 → 限定成立条件 → 提出剩余问题 | 罗列作者后突然说“研究不足” |
| 提出矛盾 | 两项有依据的事实/要求 → 为什么难以兼顾 → 待辨析关系 | 为叙事虚构对立或把所有瓶颈都写成权衡 |
| 提出假设 | 已有发现 → 可能解释及依据 → 可区分的预测 | 从现象直接跳到已证明机制 |
| 说明方案 | 对象与比较 → 观测/分析 → 如何判断 | 增加仪器数量却没有判据 |
| 凝练创新 | 现有边界 → 本项目新增思路/能力 → 可验证增量 | 重述研究内容或只有“首次” |
| 支撑可行性 | 已有证据 → 支撑的具体任务 → 尚需验证部分 | 自称基础扎实、条件优越 |
| 总结贡献 | 明确贡献判断 → 关键证据 → 适用意义 | 用期刊、引用量代替科学贡献 |
| 组织研发 | 使用约束 → 技术任务 → 测试与交付 | 把产品开发强写成机制发现 |

## 句子怎样写得自然

1. **主语可见。** 写“孔道曲折度影响输运路径”，优于连续使用“其、该作用、上述过程”而指代不明。研究动作可由项目或申请人作主语，机制解释优先让真实对象作主语。
2. **一处分句增加一种信息。** 如果“系统研究、深入揭示、全面阐明”指向同一内容，保留最准确的一个。解释、对照、结论发生转换时考虑断句，不按固定字数切句。
3. **动词匹配认识层级。** “测量”对应观测量，“比较”对应条件差异，“检验”对应假设，“揭示”对应拟获得或已有支持的机制，“建立”对应模型/方法。“本构关系”只在有本构含义时使用；一般联系不借此拔高。
4. **长短交替由功能决定。** 先用清楚判断定位，再展开必要关系；不要求每段以“针对”起句或“提供依据”收尾。总述可以概括，具体方案应落到变量与判断。
5. **保留术语，减少无谓名词化。** “研究温度如何影响晶化”通常比“开展温度影响晶化作用规律的相关研究”清楚。不能为了通俗删掉必要条件、机制限定或专业概念。
6. **并列对齐。** 并列内容属于同一层级；材料、方法、机制和应用混在一组时先厘清层次，不能只把词尾改成一样。
7. **允许有依据的力度。** 已完成贡献可直接陈述；预期认识保留计划语态。准确限定比一律改成“可能、有望”更有力。

高密度复句仍可用于研究内容：各分句依次增加研究对象/变量、动态过程、关系解释和预期认识时，长句能够保留完整链条。不同证据任务可用分号分开；主语、条件或论证方向改变时宜断句。不要为了“去模板”把真实的连续关系切碎，也不要为了像范本把几个并行任务挤成一句。

起草背景时，将证据边界转成自然的研究问题或条件限定，避免连续使用“不能等同、并不必然、尚不能证明”等检查口吻，使整段被否定句占据。例如，可写“组分设计能否带来持久隔热能力，取决于高温下相结构和纤维网络的演变”，让限定继续推进主线。若用户提供了错误事实，则应明确指出并给出可替换文本，不能以行文流畅掩盖错误。

## 连接词必须兑现关系

- “然而”前后有真实限制或反差，不能只表示换话题。
- “因此、由此”需要前文足以支持结论；若只是可能解释，改成假设并写明验证方式。
- “在此基础上”需要前一步产物确是后一步输入；并行任务用“分别、同时、从两个方面”。
- “进一步”须说明增加的尺度、条件、解释深度或验证范围；不要只是增加一个实验。
- “一方面/另一方面”必须是同一问题下的两个方面，避免把因果链拆成假并列。

## 把缺口写具体

区分观测不足、解释竞争、变量不可独立控制、模型适用边界、工况稳定性及任务集成障碍。每类缺口决定不同研究动作。现有方法已经有效的部分要保留；从“尚无报道”到“值得研究”之间还需论证价值。

“多因素耦合”后应说明可能竞争或依赖的过程，以及当前为何不能区分；未有因果证据时写关联或待检验解释。模型拟合好不能自动证明机制唯一。

## 证据放置与阅读引导

事实或数据紧跟它支持的最小判断，图表用于比较、路径或前期证据；图前说明要看什么，图后解释它支持什么。文献并列不代表结果可直接横向比较，比较时检查工况与指标定义。

小标题概括真正任务或贡献。强调文字应使读者快速找到问题、策略、证据；不要把整段加粗、把每段末尾都写成宏大意义。

P05页9–10示范有依据的转折；P08页20和P13页22示范前期发现与边界并存；P10页9示范贡献判断前置；P11页33–35示范任务衔接。它们是写法证据，非科学事实通用证明。

## 压缩与修订

先删重复意义、同义动作、无信息修饰和已在别处展开的背景，再压缩方法清单。保留科学问题、对照条件、因果限定、关键数据、成果归属和用户锁定的标题。目标是指定幅度时实际计字，并说明使用的计数口径；不要求每段等比例减少。

复核“删掉连接词后关系是否仍然成立”“段末是否出现没有铺垫的新概念”“新句是否比原句增加了未经提供的事实”。跨类型的原创示例见writing-examples.md。
