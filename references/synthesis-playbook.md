# 合成领域 Playbook

## 核心任务

回答“如何获得组元、相和局域组织可控的材料，以及为何能够形成”。标准因果链为：

`设计变量 → 前驱体/原料状态 → 分解、释放、迁移、成核与晶化 → 相与局域组织 → 可控合成方法`

## 论证重点

- 区分平衡相稳定预测与非平衡转化路径。
- 辨析构型熵、混合焓、近邻偏好与实际转化路径如何共同影响固溶、偏聚或第二相形成；不能预设所有多主元体系都由熵主导，也不能将混合焓一概写成促进偏聚。
- 不以“获得单相”替代“局域组织可控”；明确元素分布、近邻配位、缺陷及第二相的判据。
- 对照设计须能拆分热力学倾向和前驱体转化动力学的贡献。

## 章节落点

- 研究内容：研究哪些设计变量、转化过程和组织结果。
- 科学问题：平衡驱动力与非平衡路径如何耦合决定相和局域组织。
- 目标：形成可复现的合成方法、工艺窗口和形成机制，并为后续研究提供可比较样品。

## 边界

本模块输出材料、方法和形成机制；不解释裂纹强化、反应中间体或催化选择性。后续性能只是验证可控性的结果时可简述，不得反客为主。
