# 催化领域 Playbook

## 核心任务

回答“初始组元和局域组织如何在工况下转变为动态活性态，并决定载流子利用、反应路径、选择性和器件性能”。材料催化标准链为：

`初始组元/局域结构 → 工况动态价态、缺陷与吸附态 → 载流子产生、迁移与消耗 → 中间体及能垒 → 活性与选择性`

器件链为：

`代表性催化剂 → 膜/反应器结构 → 光场、浓度场与温度场 → 单位面积产率、选择性、压降与稳定性`

## 论证重点

- 静态结构不等于真实活性位点；必须观测或计算工况下价态、缺陷、配位和吸附态变化。
- 材料形成机制不等于催化作用机制；前驱体转化只负责提供可控催化剂。
- “协同催化”必须落实为连续基元步骤或不同位点的功能分工。
- 区分光吸收、载流子分离、表面消耗和热效应各自贡献。
- 用代表体系做深机制，再以扩展体系检验适用边界。
- 本征催化活性不等于器件性能；器件必须加入光、质、热传递和工程判据。

## 章节落点

- 研究内容：先比较组元组合及性能，再解析动态表面、载流子和反应路径，最后选择代表性催化剂构建设备。
- 科学问题：局域结构如何经动态活性态这一中介层决定路径和选择性；光质热如何耦合限制器件。
- 目标：获得组元/局域位点设计依据、反应机制及器件设计方法。

## 边界与依赖

催化模块以合成模块提供的精确可控样品为输入。器件模块必须以催化模块筛选出的代表性组成为输入，不得在器件部分再次承担组元筛选任务。
