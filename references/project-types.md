# 项目分类与风格选择

## 判定顺序

先看当前申报指南、正式类别和正文栏目，再看评审任务，最后才参考文件名。记录：主类别 / 叠加属性 / 阶段 / 章节 / 学科。写作时按需采用，不将这五项机械地展示给用户。

名称相近也可能文体不同：“重点项目”不等于“重点研发计划”；“青年”可能是探索类项目，也可能是人才项目；“联合基金”是资助方式，不能仅凭名称认定规模；“国际合作”既可能资助机制研究，也可能要求联合开发。用户只要求局部语言修改时，不因类别未知阻断修改。

“重大”也要核对资助体系：P04是地方教委科研创新重大项目，兼有申请人业绩、基础研究和应用考核栏目，不能仅凭金额或名称认定它代表国家自然科学基金重大项目。涉及多类评价时按实际栏目组合，不强行归入单一模板。

## 叠加属性与阶段

- **联合基金、培育项目**：在主类别上补充指南匹配与联合资源必要性。P01为依托特定设施的联合基金培育样本，只能支持这一情境；“培育”侧重哪些初步证据值得继续验证，不能包装成已有系统突破。
- **国际/多方合作**：在主类别上补充互补能力、已有合作、任务输入输出和共同判断标准。P11提供直接证据；若主类别是重点研发，仍以研发指标为主，不套科学基金栏目。
- **项目计划书**：依据批准内容写执行，不自由扩大任务。P12/P24是资助计划书，不能当成两份新的立项依据范本。
- **进展/结题报告**：写实际完成、证据、偏差与下一步，不把申请书的“拟”机械替换成“已”。P09/P23与P16是不同阶段资料。
- **答辩材料**：可用“判断句＋核心证据”压缩表达，正文则需补齐推理桥梁。P19–P22不支持把整篇申请书改成口号和短语。
- **奖励申报**：若任务确为奖励，核对奖励要求后组织已完成贡献与归属；本库P14实为五年研究计划，不能充作奖励申报样本。

## 组合示例

- 面上＋催化＋立项依据：先选面上文体，再选问题提出型段落，科学验证使用催化规则。
- 重点基础研究＋国际合作：先建立共性问题与子任务，再说明双方分别提供哪些必要输入。
- 重点研发＋国际合作：先建立技术目标、任务与验收，再说明双方如何衔接及共同验证。
- 杰青＋未来计划：从已提供的连续贡献自然引出新方向，未来部分仍用计划语态。

类别选择是写作决策，不是资助政策解释。旧范本不提供当前年龄、金额、字数、条数和资格要求。
