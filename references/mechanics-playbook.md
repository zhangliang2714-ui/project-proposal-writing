# 力学领域 Playbook

## 核心任务

回答“组织如何控制载荷传递、裂纹演化、损伤耗散和环境失效”。标准因果链为：

`初始组织 → 应力/载荷传递 → 裂纹萌生与扩展 → 单体断裂/网络损伤 → 宏观性能`

环境链为：

`环境作用 → 扩散、偏聚、相变、晶粒/节点退化 → 承载能力下降 → 失效`

## 论证重点

- 按实际科学问题选择单纤维、网络/节点或跨尺度研究，并明确需要的接口；不强制所有任务同时覆盖全部尺度。
- 涉及承载与失效的研究设计需明确组织变量、相关的载荷/裂纹中间变量和判断依据；背景或局部润色不据此增添未经提供的实验。
- “强化”必须落实为裂纹偏转、桥联、滑移、载荷重分配或损伤耗散等可观测过程。
- 环境稳定性最终回到承载与失效，不能停留在物相表征。

## 章节落点

- 研究内容：组织差异如何改变载荷、裂纹与网络损伤。
- 科学问题：不同尺度组织通过何种中间过程协同强化或诱发失效。
- 目标：建立组织—损伤—性能关系和力学设计依据。

## 边界

合成结果仅作为初始组织输入，不在本模块重新讨论材料如何形成；不得借用“活性位点、反应路径”等催化概念解释力学行为。
